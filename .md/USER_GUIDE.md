# 📖 Guía de Usuario - AI Prompt Assistant

## 🚀 Instalación Rápida

### Desde Chrome Web Store
1. Visita la [Chrome Web Store](https://chromewebstore.google.com/)
2. Busca "AI Prompt Assistant"
3. Haz clic en "Agregar a Chrome"
4. Confirma en el popup "Agregar extensión"
5. ¡Listo! El ícono 🧠 aparecerá en tu barra de herramientas

### Verificación de Instalación
- Busca el ícono 🧠 en la barra de herramientas de Chrome
- Haz clic derecho en cualquier página → verás opciones de AI Prompt Assistant
- Visita ChatGPT o cualquier AI → el panel lateral estará disponible

## 🎯 Primeros Pasos

### 1. Activar el Panel Lateral
- **Método 1**: Haz clic en el ícono 🧠 en la barra de herramientas
- **Método 2**: Usa el atajo `Ctrl+Shift+S` (personalizable)
- **Método 3**: Menú contextual → "Abrir AI Prompt Assistant"

### 2. Configuración Inicial
1. **Seleccionar Idioma**: Elige entre 13 idiomas disponibles
2. **Personalizar Interfaz**: Ajusta tema y configuraciones visuales
3. **Configurar Atajos**: Define tus atajos de teclado preferidos

### 3. Primer Prompt
1. Abre el panel lateral
2. Selecciona una plantilla predefinida o crea una nueva
3. Personaliza el texto según tus necesidades
4. Haz clic "Enviar" o usa `Ctrl+Enter`

## 🌟 Características Principales

### 🎯 Detección Automática de AIs

**Plataformas Soportadas:**
- **ChatGPT** (chat.openai.com)
- **Claude** (claude.ai)
- **Gemini** (gemini.google.com)
- **DeepSeek** (chat.deepseek.com)
- **Copilot** (copilot.microsoft.com)
- **Mistral** (chat.mistral.ai)
- **Grok** (x.ai/grok)
- **Meta AI** (meta.ai)

**Funcionamiento:**
- La extensión detecta automáticamente cuando estás en una plataforma AI
- El prompt se inserta directamente en el campo de entrada
- No necesitas copiar y pegar manualmente

### 📝 Editor de Prompts Avanzado

**Características del Editor:**
- **Sintaxis highlighting**: Resalta elementos importantes
- **Autocompletado**: Sugerencias inteligentes mientras escribes
- **Plantillas**: Prompts predefinidos para casos comunes
- **Historial**: Acceso rápido a prompts anteriores
- **Variables**: Usa `{variable}` para elementos dinámicos

**Ejemplo de Prompt con Variables:**
```
Actúa como un {profesión} experto.
Analiza el siguiente {tipo_contenido}: 
{contenido}

Proporciona:
1. {análisis_1}
2. {análisis_2}
3. {recomendaciones}
```

## ⚙️ Configuración Avanzada

### 🎨 Personalización de Interfaz

**Temas Disponibles:**
- **Claro**: Interfaz luminosa para uso diurno
- **Oscuro**: Reduce fatiga visual para uso nocturno
- **Auto**: Se adapta al sistema operativo
- **Contraste Alto**: Para mejor accesibilidad

**Personalización:**
1. Panel lateral → ⚙️ Configuración
2. Sección "Apariencia"
3. Selecciona tema preferido
4. Ajusta tamaño de fuente
5. Configura transparencia del panel

### ⌨️ Atajos de Teclado

**Atajos Predeterminados:**
- `Ctrl+Shift+S`: Abrir/cerrar panel lateral
- `Ctrl+Enter`: Enviar prompt actual
- `Ctrl+Shift+H`: Mostrar historial
- `Ctrl+Shift+T`: Nueva plantilla
- `Escape`: Cerrar modales

**Personalización de Atajos:**
1. Configuración → "Atajos de teclado"
2. Haz clic en el atajo que quieres cambiar
3. Presiona la nueva combinación
4. Guarda cambios

### 🔧 Configuraciones de Comportamiento

**Envío Automático:**
- **Activado**: Los prompts se envían automáticamente a la AI
- **Desactivado**: Solo se copia al portapapeles

**Confirmaciones:**
- **Siempre preguntar**: Confirma antes de enviar
- **Solo prompts largos**: Confirma prompts >500 caracteres
- **Nunca**: Envía directamente

**Historial:**
- **Días a conservar**: 7, 30, 90 días o indefinido
- **Máximo de prompts**: 50, 100, 500 o ilimitado
- **Incluir metadatos**: Fecha, hora, sitio web de origen

## 🛠️ Solución de Problemas

### ❌ Problemas Comunes

**El panel lateral no aparece:**
1. Verifica que la extensión esté habilitada
2. Refresca la página
3. Comprueba permisos en chrome://extensions/
4. Reinicia Chrome si es necesario

**Los prompts no se envían automáticamente:**
1. Confirma que estás en una plataforma AI soportada
2. Verifica que el campo de entrada esté visible
3. Comprueba la configuración de envío automático
4. Intenta con un prompt más corto

**La detección de idioma no funciona:**
1. Configura el idioma manualmente en Configuración
2. Refresca la página después del cambio
3. Verifica que tu navegador tenga el idioma configurado

**Problemas de rendimiento:**
1. Cierra pestañas innecesarias
2. Limpia el historial de prompts
3. Desactiva funciones no utilizadas
4. Reinicia Chrome

### 🔍 Diagnóstico Avanzado

**Consola de Desarrollador:**
1. F12 → Consola
2. Busca errores de "AI Prompt Assistant"
3. Copia el mensaje de error
4. Reporta a través del sistema de feedback

**Verificación de Permisos:**
1. chrome://extensions/
2. Busca "AI Prompt Assistant"
3. Verifica que todos los permisos estén activos
4. Reactiva si es necesario
